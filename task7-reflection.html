Reflection on Week 1: HTML Fundamentals

What I learned about HTML

I learned that HTML gives a web page its structure. I now understand the document skeleton, headings, paragraphs, links, images, lists, tables and forms, and I know why each tag is used and how elements nest inside one another. Practising each topic in a separate file made the ideas easier to remember.

Most challenging topic

Forms were the hardest part. There were many input types and attributes to remember, and I had to be careful to connect every label to its input using matching id and for values.

Concepts I enjoyed

I enjoyed semantic HTML because elements such as header, main and footer make a page easier to read. Building the mini project, where I combined everything I had practised, was also satisfying. It showed me how small pieces fit into a complete page.

How HTML will help me

HTML is the base for CSS, JavaScript and frameworks like React. Understanding it properly will help me build accessible pages and continue learning web development with more confidence.
