HTML Document Structure

This page demonstrates the basic skeleton of an HTML5 document. View the page source to read the comments.

  • <!DOCTYPE html> tells the browser this is HTML5.
  • <html lang="en"> is the root element and declares the language.
  • <head> holds metadata: title, charset and viewport.
  • <title> sets the browser tab text.
  • <meta charset="UTF-8"> sets the character encoding.
  • <meta name="viewport"> helps pages fit mobile screens.
  • <body> contains the visible content.
